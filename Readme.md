# Webpack SCSS Template
This is my simple typescript enabled webpack scss template. This is a standard (empty) template for using webpack (with live reload) with SASS loader.

## Prerequisites
 - Node version 20

## Installing
```
git clone https://github.com/folkerthoogenraad/WebpackSCSSTemplate.git [YourProjectName]
cd [YourProjectName]
npm install
```

Optionally, if you want to have a clean git history to start with:
```
rm .git
git init
```


## Running
```
npm run dev
```

## Building
```
npm run build
```
